## Part 1. Lemma 72 — the quantization, and the threshold equivalence

**Standing setup.** Fix K ∈ (0, ∞] (K = ∞ the additive convention) and a value set S with a gap: a point a with 0 < a < K, S ∩ (0, a) = ∅, {0, a} ⊆ S ⊆ {0} ∪ [a, K]. The additive instance is S = {0} ∪ [a, ∞); the capped instance (K finite) is S = {0} ∪ [a, K] — the capped instance's closure below will want a > K/2, the additive instance wants only a > 0. For a function h: W → [0, K] define the S-quantization h_S: W → S by h_S(w) = 0 if h(w) = 0, a if 0 < h(w) ≤ a, and h(w) if h(w) > a.

**Lemma 72 (the threshold equivalence) [Derived here].** (i) For every r ∈ S and every w: h(w) ≤ r ⟺ h_S(w) ≤ r. (ii) h ≤ h_S pointwise, and h_S takes values in S. (iii) Quantization is functorial along order: whenever h′(w′) ≤ h(w) (pointwise, after any carrier maps), then h′_S(w′) ≤ h_S(w). (iv) Consequently, for objects C = (A_C, X_C, r_C) with r_C S-valued, the (L)-conditions for a candidate morphism C → (X, h) and C → (X, h_S) — same carriers, pairings h and h_S — define the same set of morphism pairs. *Proof.* (i): r = 0 forces h(w) = 0 ⟺ h_S(w) = 0. r ≥ a: if h = 0 both sides hold; if 0 < h ≤ a then h ≤ a ≤ r and h_S = a ≤ r; if h > a then h_S = h and the two inequalities are the same. (ii) is immediate from the definition (h_S = h outside the gap's preimage, a inside it, 0 at 0). (iii): case h(w) = 0 — then h′(w′) = 0, so h′_S = 0 = h_S; case 0 < h(w) ≤ a — then h_S(w) = a and h′(w′) ≤ a, so h′_S ∈ {0, a}, both ≤ a; case h(w) > a — then h_S(w) = h(w) ≥ h′(w′), and h′_S is either ≤ a < h(w) or equals h′(w′) ≤ h(w). (iv): the (L) condition reads h(F(c), y) ≤ r_C(c, G(y)) against h_S(F(c), y) ≤ r_C(c, G(y)); the entries r_C(c, G(y)) lie in S, and (i) applies pointwise. ∎

The lemma is the whole engine, and its reading is the document's thesis in miniature: an S-valued scale of tests cannot distinguish a pairing from its quantization, because a threshold placed anywhere inside the gap (where h may sit) and a threshold placed at the gap's edge (where h_S sits) cut the same S-valued possibilities. The coupling phenomenon of Proposition 61 — objects outgrowing their probes — here takes its most arithmetic form: the probes are blind to an interval of values, and everything the construction does, it does inside that interval.

## Part 2. Theorem Z — the construction, and the refutation

**Theorem Z (the unit-inclusive implication, refuted at its plain form) [Derived here; Theorem A is doc 27's, Proposition 67 is doc 66's].** In the additive home ChuCost, and in the capped home ChuCost^[0,K]_⊕ for every K with the gap point chosen in (K/2, K), there exists a full replete tensor-closed subcategory containing the monoidal unit — and, in the capped home, the dualizer — which is internally adjointed in the plain sense and not residuum-closed. *Proof.* **The fragment.** Q′ := the full subcategory on the objects (A, X, r) with A, X finite and r S-valued. **(a) Full and replete.** Full by definition. Repleteness: an isomorphism (f, g) with lax inverse forces s(f(a), y) = r(a, g(y)) pointwise (each inequality against the other), so pairing values and carrier cardinalities are preserved exactly — the class is closed under isomorphism. **(b) The distinguished objects.** I = (1, 1, 0) ∈ Q′ (0 ∈ S); capped, D = (1, 1, K) ∈ Q′ (K ∈ S). **(c) Tensor-closed.** The tensor's carriers (C × A, Z^A × X^C) are finite for finite factors. Its pairing composes u ⊕ r (capped) or u + r (additive) through the crossed readings: if either entry is 0 the value is the other entry, in S; if both are ≥ a, the capped value is min(u + r, K) = K (u + r ≥ 2a > K by the choice a > K/2), and the additive value is u + r ≥ 2a ≥ a — in S either way. **(d) Not residuum-closed.** Capped: A = (1, 1, ≡a) and B = (1, 1, ≡K) lie in Q′, and A ⊸_⊖ B = (1, 1, ≡max(K − a, 0)) = (1, 1, ≡K − a) with K − a ∈ (0, a) — outside S. Additive: A = (1, 1, ≡1.5a), B = (1, 1, ≡2a), and A ⊸ B = (1, 1, ≡0.5a), outside S. **(e) Internally adjointed, plainly.** For A, B ∈ Q′ let R_A(B) be the object with A ⊸ B's carriers (finite: exponentials of finite sets) and pairing (h_⊸)_S — the S-quantization of the ambient hom's pairing. By Lemma 72(ii) its values lie in S, so R_A(B) ∈ Q′. For C ∈ Q′, Lemma 72(iv) identifies the morphism sets: ChuCost(C, A ⊸ B) = Q′(C, R_A(B)) — not a bijection of constructions but the same set of carrier pairs, the two (L)-conditions being pointwise equivalent against r_C's S-valued entries. Composing with the ambient adjunction — Theorem A additively, Proposition 67(i) capped, both natural in C and B — gives bijections Q′(A ⊗ C, B) = ChuCost(A ⊗ C, B) ≅ ChuCost(C, A ⊸ B) = Q′(C, R_A(B)), natural in C (precomposition; the identification never moves underlying data) and in B (doc 27's functoriality-in-B computation on carriers, with Lemma 72(iii) carrying each inequality through the quantization, so the induced maps R_A(B) → R_A(B′) and the unit and counit are Q′-morphisms — the case analysis is Lemma 72(iii) verbatim, plus monotonicity of ⊕ for the counit's condition: the ambient counit's inequality survives the replacement of h by h_S ≥ h). By the standard criterion, A ⊗ − admits the right adjoint R_A on Q′, for every A ∈ Q′. ∎

**The witness, read aloud (capped).** The fragment contains a = (1, 1, ≡a) and the top D = (1, 1, ≡K). The ambient computes their hom as the distance between the singletons, K − a — the full budget minus the gap point, an object outside the fragment. The fragment computes it as a itself: R_a(D) = (1, 1, ≡a), because the quantization lifts every value inside the gap to the gap's edge. Both answers are correct against every test the fragment can pose — Lemma 72(i) — and they differ. The corrected implication wanted the fragment's own function space to force the ambient's; the construction shows the two can disagree by exactly the gap, invisibly.

**Corollary Z.1 (the fence instantiated, the detections consistent) [Derived here].** (i) Definition 59's comparison χ_{A,B}: R_A(B) → A ⊸ B is the identity on carriers — a genuine ambient morphism by Lemma 72(ii) (h ≤ h_S) — so Proposition 61's probe-equality is here literal: the map the implication must identify is the identity on everything the fragment can see, differing only inside the invisible interval. The incorrigibility fence is not merely respected; it is exhibited with its mechanism open. (ii) Q′ coseparates nothing: the ambient objects (1, 1, ≡K − a) and (1, 1, ≡a) are non-isomorphic and Q′-probe-equal (Lemma 72(i) at every test) — Theorem T's hypothesis fails exactly as it must for a counterexample to survive. (iii) Q′ is not arithmetic: Definition 62(iii) fails, since hom-sets between finite objects depend on the arrangement of pairing values, not on any isomorphism-invariant profile — two same-carrier objects with the same value multiset arranged differently admit different maps from a test object — so Theorem U's hypothesis fails too. The counterexample sits in the region doc 58's map reserved for the question's whole remaining content: non-rigid, non-coseparated, and — now built — unit-containing.

## Part 3. The MV home's resistance, the retractions, and what survives

**Proposition 73 (the MV home resists the route) [Derived here].** (i) No bottom-gap value set is ⊙-closed except the Boolean exception: for S = {0} ∪ [a, K] with a < K, either a > K/2 and a ⊙ a = 2a − K lands in (0, a), or a ≤ K/2 and a ⊙ (K − a/2) = a/2 does — both outside S; at a = K the set is {0, K}, which is ⊙-closed and also ∸_MV-closed (the four pairings compute to {0, K}), hence residuum-closed and no counterexample. (ii) The top-gap sets S = [0, b] ∪ {K}, b < K/2, are ⊙-closed (values below b compose to 0; b ⊙ K = b; K ⊙ K = K), contain the unit (1, 1, K) and the dualizer (1, 1, 0), and are not residuum-closed: (1, 1, ≡b) ⊸_MV (1, 1, ≡0) = (1, 1, ≡min(K, K − b)), and K − b ∈ (b, K) — outside S. (iii) On these fragments the quantization route to internal adjointedness fails provably: the natural candidate R_⊥(⊥) is the quantization of ⊥ ⊸_MV ⊥ = (1, 1, ≡K) = I, and the required bijection fails at the corner — Q′(⊥ ⊗_MV ⊥, ⊥) = Q′(⊥, ⊥) is a one-point set while Q′(⊥, I) is empty (the condition K ≤ 0) — Lemma 66's scalar obstruction (0, 0, 0) localizing inside the fragment itself. Whether some other construction adjoints these fragments is open; the MV unit-inclusive implication's status is open with this route closed. *Proof.* (i) and (ii) are the displayed arithmetic; (iii) is Lemma 66's computation read at the fragment's own objects. ∎

**The retractions, stated plainly.** First: doc 66's ledger sentence "the one-morphism tensor-idempotents of the additive scale are the singletons (1, 1, c) with 2c = c — that is, I alone" is corrected — in ([0, ∞], +) the equation 2c = c holds at c = ∞ as well, and (1, 1, ∞) is a second one-object ⊗-idempotent; it is harmless (its self-hom is (1, 1, ∞ ∸ ∞) = (1, 1, ∞) — the residuum sends ∞ → ∞ to ∞ — so the singleton does not escape its own function space and is residuum-closed), but "alone" was wrong and the record now says so. Second, and load-bearing: doc 66's filed reduction — "any additive counterexample must be an infinite-carrier ⊗-idempotent... Filed: the additive implication stands or falls on the idempotent route" — is **retracted in part**: the necessity argument, whatever its force, applied to counterexamples of Theorem X's one-object pattern, and the value-gap construction is not of that pattern — it is multi-object, every object finite-carrier, its only idempotent the unit every fragment owns. The additive implication falls (Theorem Z, additive instance), and the idempotent route — with its centrality obstruction, filed and priced — turns out to have been beside the point: the obstruction guarded a door the counterexample does not use.

**What survives, and the dichotomy it states.** The Con-enriched unit-inclusive implication — Definition 55(b) at full strength (the bijections affine in the Con-action, on homs carrying convex structure) plus the unit — remains open in all three homes, and Theorem Z gives its openness a sharper meaning than "unproved": the plain form is false, so any proof of the enriched form must spend the enrichment — the convex structure must do work that no set-level argument can do, closing a gap that Lemma 72 shows is invisible to every plain test. The dichotomy, stated exactly: either the enriched implication holds, and convexity is what closes Proposition 61's fence (a theorem about the fibers' world that would explain, retroactively, why the corpus's applications were never threatened by the plain failure), or an enriched counterexample exists, and the enrichment was never the point — the coupling's invisibility is not a convexity phenomenon but an arithmetic one, as Theorem Z's interval already suggests. The corpus does not choose; it records that the choice is now the question. And it records the route map: the additive and capped homes are closed by Theorem Z; the MV home is open with the quantization route closed by Proposition 73; the enriched question is the corrected-corrected residual, filed in all three.
